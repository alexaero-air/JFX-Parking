# Парковка аэропорта

Контрольная точка №2. Система учёта автомобилей на платной парковке: Java 21, JavaFX, Gradle.

## Запуск в IntelliJ IDEA

1. **File → Open** и выберите папку проекта.
2. Дождитесь импорта Gradle.
3. Откройте `src/main/java/parking/Main.java` и нажмите **Run** или `Shift+F10`.
4. Либо справа откройте панель **Gradle → kt2 → Tasks → application → run**.

Журнал каждого запуска сохраняется в каталог `journals/`. Старые файлы не удаляются.
